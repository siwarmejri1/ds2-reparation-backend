# DS2 Backend-Mini-Project
## Realised by :
- Mejri Siwar

### Description
Backend API developed with **NestJS + MySQL** for an electronic device repair and refurbishment company. This project implements a complete management system with role-based access control, inventory management, and repair tracking.

### Quick Start
#### Prerequisites
- **Node.js** 18 or higher
- **MySQL** 8.0 or higher
- **npm** or **yarn**
